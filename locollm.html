Our team was asked to build the first real adapter and prove, with numbers, whether the idea works.

2. Context

2.1 What we want to achieve

Same laptop, same base model, same question. One small adapter file makes the difference.

2.2 What is LocoLLM

A project by LocoLabo, a research lab at Curtin Business School: one small open model (Qwen3-4B) that runs privately on your own laptop, plus plug-in adapters that each make it a specialist. No adapter had been built yet, and nobody had proof the idea works at this size.

2.3 Why privacy law was a weak spot

On 20 privacy scenarios the base model scored 10%, about the same as guessing. It knew the law existed but mixed up the principle numbers, and invented its evidence.

2.4 What a good answer looks like

3. Methodology

3.1 Tested the base model on 15 domains

If the base model is already good, a small gain proves nothing. We needed a domain with room to improve.

We asked the untrained model 5 questions in each of 15 business domains. Eleven scored 5 out of 5. Compliance and privacy law scored 0, so the client approved it as our domain.

Build the test before the result

On LocoLLM we sealed a 170-question benchmark before any training. When I found 30 of my training questions described the same situations as test questions, I rewrote them, so the 81% measures what the model learned, not what it memorised.

5. Deliverables and recommendations

5.1 What LocoLab gets

All in the shared repository: the privacy-law adapter, the sealed 170-question benchmark with its scoring script, the 615-example training set, a repaired one-click Colab notebook, and a report on every run.

5.2 Three recommended changes and a six-step recipe

Three recommended changes

ChangeEffect
Train the MLP layers too, one line of settings38% to 81%
Reasoning first, then the answerWrong “no principle” guesses: 54 to 5
Test every recipe at least twiceA new random seed flipped 1 answer in 5

All three are free: no new data, no new hardware, the same 15-minute training.

The six-step recipe for the next domain

  1. 1Build and seal the test
  2. 2Agree one answer format
  3. 335 to 50 examples per topic
  4. 4Score the base model first
  5. 5One change per run
  6. 6Test more than once

Follow the six steps, and the next team can reach our Run 5 result in week one, not week six.

5.3 What we learned, and what is still open

  • Small can be smart: a laptop-sized model learned a narrow domain from 615 examples.
  • Format comes before facts: Run 1 used the right layout 169 times but named the right principle only 42 times.
  • Still open: questions with several right answers, a lawyer’s sign-off on some answers, and more varied question wording.
